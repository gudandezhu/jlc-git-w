# 项目 CLAUDE.md 覆盖 Demo

以下是一个完整的项目 CLAUDE.md 示例，展示业务线如何覆盖 to-prd 适配层。

复制到你的项目根目录 `CLAUDE.md` 中，按需修改。

---

```markdown
# 项目说明

本项目是 XX 业务线的产品管理知识库。

## to-prd 配置

| 配置项 | 值 |
|--------|-----|
| to-prd.prd-template | 规范/模板/PRD/XX-标准PRD模板.md |
| to-prd.encoding-source | 业务知识库/功能树/ |
| to-prd.review-dir | 规范/评审标准/ |
| to-prd.promotion-template | 规范/模板/运营宣发/XX-运营宣发模板.md |

## 目录结构

```
项目根目录/
├── docs/
│   ├── prd/               # PRD文档
│   └── ui/                # UI原型
├── 任务/                   # 任务记录
├── 记忆/                   # 经验积累
└── 规范/                   # 规范体系
```

## 任务流程

```
创建 → 内部评审（产品负责人+技术负责人）→ 执行 → 完成 → 归档
```

## 文件命名

- PRD：`[功能名称]-PRD-v[版本号].md`
- 任务：`YYYY-MM-DD_任务名称.md`

## Git 提交格式

```
类型: XX-问题ID 描述
```

## 编码体系

本业务线使用 `XX-` 前缀编码体系，编码数据源位于 `业务知识库/功能树/`。
```

---

## 说明

- 以上为全量覆盖，所有适配层配置项都需要写明
- 未列出的配置项使用 to-prd 默认值
- 不需要的配置项写 `无` 或直接删掉对应行
